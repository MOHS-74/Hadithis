# 📚 Hadithis | مكتبة الحديث

موقع ويب بسيط لعرض مجموعة من أشهر كتب السنة النبوية، مع إمكانية اختيار الكتاب وتصفح الأحاديث واحدًا تلو الآخر.

تم تنفيذ المشروع باستخدام HTML وCSS وJavaScript، مع الاعتماد على API لجلب بيانات الأحاديث بشكل ديناميكي.

---

## ✨ مميزات المشروع

- 📚 عرض مجموعة من كتب الحديث.
- 🔎 جلب الكتب والبيانات بشكل ديناميكي من API.
- 📖 تصفح أحاديث كل كتاب.
- ⬅️ الانتقال إلى الحديث السابق.
- ➡️ الانتقال إلى الحديث التالي.
- 🔢 عرض رقم الحديث الحالي وإجمالي عدد الأحاديث.
- 🔙 العودة إلى قائمة الكتب.
- ⏳ التعامل مع حالة التحميل.
- ⚠️ التعامل مع أخطاء تحميل البيانات.
- 📱 تصميم متجاوب مع الشاشات المختلفة.
- 🎨 واجهة بسيطة وهادئة مناسبة لطبيعة المحتوى.

## 🧠 ماذا تعلمت من المشروع؟

كان الهدف من المشروع تطبيق بعض المفاهيم بشكل عملي، ومنها:

- التعامل مع الـ APIs.
- استخدام `fetch()` لجلب البيانات.
- التعامل مع البيانات القادمة بصيغة JSON.
